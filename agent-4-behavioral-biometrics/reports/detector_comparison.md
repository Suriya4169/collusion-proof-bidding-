# Gaussian mixture or Isolation Forest?

Generated by `python -m agent4 compare-detectors`; every number below is computed, none is typed by hand.

The original design of this module used an Isolation Forest. The shipped model is a Gaussian mixture. Both are implemented here and served the same way (a JSON bundle scored with NumPy only), so they can be compared directly. `models/` holds the mixture; `models_iforest/` holds the forest, and either can be served with `AGENT4_MODEL_DIR`.

## Protocol

* Data: the same simulated sessions for every detector (seed 42, 6,000 per class, 39,000 sessions). Detectors are fitted on genuine-human sessions only and never see an attack.
* Calibration: each detector is calibrated on the same disjoint human calibration split to the same scale (risk 50 = the 95th percentile of humans of similar length), so every detector is held to the same ~5% false-alarm budget.
* Evaluation: held-out human test split and every attack session, with 95% Wilson intervals, by the same code that produced `reports/metrics.json`.
* The forest variant that ships (`Isolation Forest, PCA-whitened`) was chosen on a separate development dataset before these held-out numbers were computed (`reports/model_selection_full.json`).
* The mixture re-evaluated here reproduces the published `reports/metrics.json`.

## Reading

At the same human false-alarm budget, the full model's macro detection over the three core attack classes is 84.9% for the mixture, 82.4% for the whitened forest and 67.5% for the forest as originally built. The differences sit in the attacks designed to look human. Adaptive bot: 54.6% (mixture), 47.3% (whitened forest), 2.4% (plain forest). Mimic bot: 44.7%, 19.4% and 4.0%. Scoring a session takes 1.2 times as long with the forest (0.39 ms against 0.33 ms) and its bundle is 4.1 times as large; both are small enough not to matter.

What the numbers support: whitening the features before the forest raises adaptive-bot detection from 2.4% to 47.3%. These bots keep each feature inside the human range and get the *combination* of features wrong; a forest that splits one feature at a time is poorly placed to see that until the features are decorrelated. A mixture of full-covariance Gaussians models the joint distribution directly, and it still detects more of the adaptive and the mimic bots. That is the reason the mixture is the production detector. It is an interpretation of these results, not a separate experiment.

## What this does and does not show

* Every number comes from simulated typing. It compares the two methods under one set of assumptions; it does not say how either performs on real bidders. Retrain on real genuine sessions (`python -m agent4 retrain`) before relying on either.
* The comparison is for this feature set and these attack classes. A different attacker, or different features, could change it.
